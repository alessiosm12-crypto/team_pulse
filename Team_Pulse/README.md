# Team Pulse Local Prototype

Локальный прототип Team Pulse работает как статическое HTML-приложение без установки зависимостей.

## Как запустить

Откройте файл `index.html` в браузере.

## Что уже работает

- прохождение опроса участником;
- сохранение ответов в `localStorage` браузера;
- загрузка тестовых ответов;
- расчет средних оценок по блокам;
- определение зеленой / желтой / красной зоны;
- отображение дословных комментариев;
- генерация Markdown-отчета;
- копирование и скачивание отчета.

## Ограничения текущей версии

- данные хранятся только в браузере;
- AI-анализ пока заменен локальной rule-based логикой;
- нет Telegram-бота;
- нет backend и общей базы;
- нет авторизации и ролей.

## Следующий технический шаг

Подключить реальный AI-анализ:

1. вынести ответы в JSON;
2. отправлять агрегированные данные и комментарии в AI API;
3. использовать `prompts/analysis_prompt.md`;
4. сохранять версию промпта и сгенерированный отчет.
